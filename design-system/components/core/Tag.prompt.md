Small square chip. Decorative variants carry no meaning; semantic ones do, and render
a leading glyph so the meaning survives greyscale.

```jsx
<Tag variant="accent">synced</Tag>
<Tag variant="neutral">main - 1 change</Tag>
<Tag variant="outline">L2</Tag>
<Tag variant="success">2 added</Tag>
<Tag variant="warning">3 changed</Tag>
<Tag variant="danger">merge conflict</Tag>
```
