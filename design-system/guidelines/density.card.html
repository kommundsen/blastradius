Density changes rhythm — control height, row padding, gutters — and deliberately not type size: legibility should not depend on how tightly the user packs their panels, and the AA audit assumes a fixed type scale. The steps are discrete values, not a scalar multiplier, which would reintroduce the fractional pixels the whole-pixel spacing rebase removed.

The shell is .app > .app-bar + .app-body > .panel-nav | .canvas | .panel-side. Panels clamp between a min and a max; the canvas never yields below --canvas-min (360px). .app-body is the query container, so panels respond to the window, not the viewport — at 800px the source panel floats over the canvas instead of stealing width, at 560px the model tree does too.
